# 50+ Maneiras de Fazer Café — App Premium

Entregável estático, mobile-first e compatível com GitHub Pages.

## O que contém
- 78 receitas/estilos;
- página individual completa para cada preparo;
- ingredientes com checklist;
- moagem, temperatura, proporção, rendimento, equipamento e perfil;
- passo a passo;
- modo preparo guiado;
- cronômetro livre;
- troubleshooting;
- contexto cultural/editorial;
- variações;
- favoritos;
- progresso;
- notas pessoais;
- busca e filtros;
- navegação por país;
- PWA/offline básico.

## Publicar no GitHub Pages
Envie **o conteúdo desta pasta** para a raiz de um repositório.
Depois: Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Acesso
GitHub Pages é hospedagem pública. `robots.txt` e `noindex` reduzem indexação, mas **não são proteção de acesso**.
Para um paywall real, use autenticação/área de membros ou hospedagem com controle de sessão.

## Conteúdo
As receitas ficam em `js/data.js`.
O visual está em `css/style.css`.
